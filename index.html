🔐 IAM ဆိုတာဘာလဲ?

English: AWS IAM (Identity and Access Management) is a service that helps you securely control access to AWS resources. It lets you define who can do what—and under what conditions.

မြန်မာ: AWS IAM ဆိုတာကတော့ AWS resource တွေကို ဘယ်သူတွေ လုပ်ဆောင်ခွင့်ရှိတယ်၊ ဘယ်အခြေအနေမှာ လုပ်ဆောင်လို့ရတယ် ဆိုတာကို ချမှတ်ပေးနိုင်တဲ့ လုံခြုံရေး service တစ်ခုဖြစ်ပါတယ်။

🛠️ Use Cases

  • English: Create roles for EC2 instances
  • မြန်မာ: EC2 နဲ့ပတ်သက်တဲ့ roles ဖန်တီးခြင်း
